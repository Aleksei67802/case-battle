# Case Battle — Telegram Mini App demo

Это первая локальная демо-версия интерфейса.

## Запуск
Нужен любой статический HTTP-сервер. Например:

```bash
python -m http.server 8080
```

Открой:
http://localhost:8080

Для Telegram Mini App сайт нужно разместить на HTTPS-хостинге и указать URL в BotFather.

## Что уже есть
- красивый экран кейса;
- баланс;
- открытие кейса;
- редкости предметов;
- ножи и оружие как демонстрационные иконки;
- инвентарь;
- Battle против бота;
- адаптация под мобильный экран;
- Telegram WebApp SDK.
