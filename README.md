# CASE BATTLE V3

Новая статическая версия демо для GitHub Pages / Telegram Mini App.

## Что добавлено

- 4 разных кейса
- рулетка открытия с анимацией
- 4 уровня редкости
- ножи и оружие в виде демонстрационных иконок
- инвентарь
- фильтр по редкости
- продажа предметов за игровую валюту
- сохранение баланса и инвентаря через localStorage
- Battle vs Bot
- адаптация под телефон
- Telegram WebApp SDK

## Установка

Замени в репозитории `index.html`, `style.css`, `game.js` этими файлами и обнови GitHub Pages.

Это клиентский прототип: баланс, инвентарь и выпадения находятся в браузере. Для реального Telegram-проекта нужны backend, база данных, авторизация через Telegram initData и серверная логика выпадений.

Иконки оружия в этой версии — emoji-заглушки, чтобы не использовать чужие изображения без разрешения.
